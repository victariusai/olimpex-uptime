# olimpex-uptime

Внешняя проверка доступности https://olimpex.pro — запускается в GitHub Actions каждые 5 минут
и пишет в Telegram, если сайт не открывается из интернета.

Зачем отдельно от сервера: сторож на самом сервере (`server/health_watch.py`) не видит аварию,
при которой машина жива, а мир до неё не достучится — ровно это случилось 12.09.2026, когда у
хостера упал международный транзит.

Секреты репозитория (Settings → Secrets and variables → Actions):
- `TG_TOKEN` — токен СЕРВИСНОГО бота @Olimpex_Service_bot (служебные оповещения отделены от клиентской поддержки);
- `TG_CHAT` — chat_id получателя.

Кода проекта здесь нет — только этот workflow.
